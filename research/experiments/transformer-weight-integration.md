# Matched transformer release-package integration test

This tests a **rebuild**, not the July award. Use the pinned portable source `83f2603f3f7751da5f429fd32669807eb8510494`, its optimized native x86-64-v3 release recipe (Clang 17, seed 923, update limit 3000, PGO/LTO, stripped, UPX `-9`), and one shared profile from its 50,051-byte `prof_input/input`. The transformer loader is deliberately not PGO/LTO compiled upstream. Use identical build paths and settings. The only source changes allowed in the candidate are the previously validated static-table loader and recognition of its magic by the inference loader. The verified weight files are reused, not regenerated.

Keep the packed dictionary and order data and already-compressed corpus stream from the public **portable fixed** pair common to both arms. Parse and recover the donor package layout before replacing anything. Reassemble and parse each on-disk `cmix` and `archive9`; count their actual lengths, not ELF sections or the model in isolation. No executable is to be run on the donor corpus payload. Stop if the combined gain is not positive (52,806 B or more added outside the weights).

If smaller, test the packed programs' supported short-input transformer interface (`-n --transformer`, then `-d --transformer`), not `-s` or an LSTM-only default. A synthetic 10,240-byte fixture repeats byte values 0…204 and is truncated at 10,240; its SHA-256 is `443f66215cc8c604ef1f20e651da6af53f93e122528b153cbca4f8564cc2e8d5`. This passes the upstream minimum of 10,000 preprocessed bytes and exactly 205 distinct byte values. The `-n` mode disables preprocessing transforms, **not prediction**; it adds a 5-byte segment header. Use each packed program's own model bytes. Check the non-storage stream header, nonempty transformer-probability trace and direct payload equality. Give the candidate decoder only its own program, its embedded model extracted from that archive, and the short encoded stream; compare the restored bytes outside the sandbox. Keep only if both byte comparisons pass. This is not a test of the enwik9-only article remapper, donor-payload compatibility, eligibility, or a prize score. Do not disturb any existing replay.
