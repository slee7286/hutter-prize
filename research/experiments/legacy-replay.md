# Replaying the four enwik8 winners

All four original award-size executables were recovered. The two PAQ families passed an 8,192-byte round trip using native variants. The two decoder-only submissions started on their original archives; neither bounded startup test establishes a full decode.

## Evidence and provenance

Local artifacts are under `build/legacy-replay/`. `manifest.tsv` records bytes and SHA-256 for downloaded packages and extracted members (paths relative to that directory). These are local fingerprints, not publisher signatures. `packages/` retains the containers; `members/<id>/` retains their contents. Sources:

- Original PAQ ZIPs, members 8 and 10: [hp5 snapshot](https://web.archive.org/web/20070622150239id_/http://www.binet.com.ua/~artest/HKCC/paq8hp5.zip), [hp12 snapshot](https://web.archive.org/web/20070622150418id_/http://www.binet.com.ua/~artest/HKCC/paq8hp12.zip). The originals are not the larger Windows executables in the source distributions.
- Mahoney mirror: [hp5 source, 0](https://mattmahoney.net/dc/paq8hp5s.rar), [Georgiev Linux port, 1](https://mattmahoney.net/dc/paq8hp5l.rar), [hp12any, 4](https://mattmahoney.net/dc/paq8hp12any_src.zip), [May winner, 5](https://mattmahoney.net/dc/decmprs8.zpaq), [April predecessor, 7](https://mattmahoney.net/dc/decomp8b.zpaq), [2017 winner, 6](https://mattmahoney.net/dc/HP_2017_October.rar). The Linux hp5 release contains source and a 32-bit object, not a Linux executable. `members/port` is the local x64 build: embedded the supplied LF dictionary using the release build script’s quoted-line format and compiled with `g++ -std=gnu++98 -fpermissive -fwrapv -DNOASM -O2 paq8hp5.cpp -o paq8hp5`. No model edits.
- [Public phda9 ZIP, 9](http://qlic.altervista.org/phda9.zip) retrieved over HTTP (TLS hostname mismatch); this is the later enwik9-era package, **not** evidence of a compatible 2017 encoder. Its readme specifies ~6 GiB for enwik9 and warns against using `C9` on other inputs. General-mode `phda9 C enwik8 archive` on the fixture terminated under the capped scope (return −15); precise cause not established. No full run scheduled for it.
- Windows runtime: portable [Wine 11.22 WoW64](https://github.com/Kron4ek/Wine-Builds/releases/tag/11.22), no host installation or shared Wine prefix. Both architectures of [wibo 1.2.0](https://github.com/decompals/wibo/releases/tag/1.2.0) returned 139 on the three original PE probes; those are runtime failures, not archive-corruption findings.

## Verification and full queue

Reference: first 100,000,000 bytes of `data/enwik9`, SHA-256 `2b49720ec4d78c3c9fabaee6e4179a5e997302b3a70029f30f2d582218c024a8`, MD5 `a1fa5ffddb56f4953e226637dabbb36a`. Both PAQ tests used a file literally named `enwik8`; the runner removed it before extraction so an archiver’s compare-existing-file path cannot masquerade as a decode. The verified fixture SHA-256 was `b4a8bf3f56f0fcabc2a6d8fe6814c266ae9802db1ecd7cc2ae655c310f585d37`.

Probe receipts: `probe-hp5-ansu0qcq` (original), `probe-hp5port-ehpeug5t`, `probe-hp12-miiuvfg_` (original), `probe-hp12any-750_x_yo`, `probe-decomp8-7tdqzdkr`, `probe-phda-7iv_szfa`, `probe-public-y7kw0to4`. Each contains exact argv, log and result JSON. Outer `*.time` RSS describes the wrapper, **not** the codec. The resource limit is enforced by the user scope: `MemoryMax=1800M`, `MemorySwapMax=0`, `AllowedCPUs=7`, plus `taskset -c 7`, nice 19 and idle I/O priority. STARLIT’s observed worker was pinned to CPU 0 (SMT sibling 8); it was not modified. All legacy executables ran unprivileged in `bwrap --unshare-all`, without host networking, home, or repo mounts, and with a private writable working directory.

Full worker command (serial, not four concurrent processes): `python3 research/tools/legacy_replay.py full phda decomp8 hp12any hp5port`. Each phase has a 24-hour cutoff. Results go to distinct `full-<case>-*/result.json` files. `verified` means reconstructed bytes hash to the reference and the decoder exited zero. For PAQ also check `award_size_match`: round-trip success alone does not reproduce a prize size, and size equality alone does not prove archive bit identity. An absent result file is not a pass. Re-running this command starts new work; consult the quiet-job receipt first.
